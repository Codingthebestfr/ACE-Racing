{% if current_lang == 'en' %}WHO WE ARE{% else %}WER WIR SIND{% endif %}

{% if current_lang == 'en' %}A.C.E. Racing is the STEM Racing team of Einhard-Gymnasium Aachen for the 2026/27 season. Racing ist das STEM-Racing-Team des Einhard-Gymnasiums Aachen für die Saison 2026/27. Wir sind fünf Schülerinnen und Schüler mit unterschiedlichen Verantwortungsbereichen und arbeiten auf ein gemeinsames Ergebnis hin: einen gut entwickelten Rennwagen und eine klare, glaubwürdige Projektgeschichte.{% endif %}

{% if current_lang == 'en' %}Our work combines technical development with communication, documentation and project organisation. Wir bauen also nicht nur das Auto, sondern erklären unsere Entscheidungen, dokumentieren unseren Fortschritt und präsentieren das Projekt gegenüber Partnern, Jurys und Besuchern.{% endif %}

{% if current_lang == 'en' %}WHAT IS STEM RACING?{% else %}WAS IST STEM RACING?{% endif %}

{% if current_lang == 'en' %}A miniature race car. A multidisciplinary challenge.{% else %}Ein kleiner Rennwagen. Eine vielseitige Herausforderung.{% endif %}

{% if current_lang == 'en' %}STEM Racing is an international, Formula 1-endorsed education competition. Teams of 3-6 students aged 9-19 design, make, test, brand and race miniature cars while presenting the thinking behind their work.{% else %}STEM Racing ist ein internationaler, von Formula 1 unterstützter Bildungswettbewerb. Teams aus 3-6 Schülerinnen und Schülern im Alter von 9-19 Jahren entwerfen, fertigen, testen, vermarkten und fahren Miniatur-Rennwagen und präsentieren die Entscheidungen hinter ihrer Arbeit.{% endif %}
